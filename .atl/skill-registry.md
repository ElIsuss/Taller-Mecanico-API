- **local_path**: `.agents/skills/fastapi`
- **description**: FastAPI best practices and conventions for APIs, Pydantic models, dependencies, SSE streaming, and serving frontend apps.

**Compact rules:**
- Use `Annotated[..., Depends(...)]` for dependencies; create reusable type aliases (`CurrentUserDep = Annotated[dict, Depends(...)]`).
- Prefer return types for validation/serialization; use `response_model` only when public schema differs from return value.
- Do not use `...` (Ellipsis) for required path params or model fields; do not use Pydantic `RootModel`.
- Declare router-level `prefix`, `tags`, and shared `dependencies` on `APIRouter` instead of in `include_router()`.

- Stream SSE with `response_class=EventSourceResponse` and `yield`.
- One HTTP operation per function; do not mix operations in a single function.
- Do not use deprecated `ORJSONResponse`/`UJSONResponse`; let Pydantic serialize on the Rust side.
- Use `fastapi dev` / `fastapi run` CLI; declare entrypoint in `pyproject.toml` `[tool.fastapi] entrypoint`.

## 6. alembic

- **local_path**: `.agents/skills/alembic`
- **description**: Alembic migrations on SQLAlchemy 2.x across SQLite, PostgreSQL, and MySQL from a single history: env.py/alembic.ini wiring, autogenerate+review, upgrade/downgrade, batch (move-and-copy) for SQLite, head merge, create_all vs Alembic decision, baseline-stamp.

**Compact rules:**
- Wire `alembic.ini` + `env.py` to `Base.metadata`; source DB URL from environment (never commit a literal URL).
- Set `target_metadata = Base.metadata` and import model modules so autogenerate sees every table.
- `render_as_batch=True` + `naming_convention` so SQLite uses move-and-copy while PG/MySQL emit plain `ALTER` from the same script.
- Autogenerate drafts; review and edit every generated script before applying (renames = silent data loss if unreviewed).
- Every `upgrade()` must have a true-inverse `downgrade()`; no `pass` downgrades on reversible ops.
- Resolve multiple heads with `alembic merge`; never hand-edit `down_revision`.
- Prefer the sync runner; async only via `run_sync` greenlet bridge when no sync driver URL is available.
- `alembic stamp head` to adopt Alembic on a `create_all`'d DB; `create_all` only for greenfield/dev/test bootstrap.
